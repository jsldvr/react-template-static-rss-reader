# CONTRIBUTING? 🤨

Yo fam, welcome to the *most* locked-down repo in the multiverse. Read this before you even **think** about hitting that fork button. 🛑

## 🔒 Pull Requests? Nah.
- PRs are on hard lockdown. Like, Fort Knox levels. Only core homies with VIP badges drop commits.
- Random drive-by PR? Auto yeet. No cap.
- Wanna sneak in a typo fix? Cute. Still gonna get bounced. 🤷

## 🦾 Issue Vibes
- Issues are for confirmed Level-99 Bugs™ only. No feature pitches, no vibes, no “what if we…” takes.
- If you *do* spot a legit bug, bring receipts: repro steps, browser deets, why it’s broke. Otherwise it’s getting ghosted.
- Meme issues for clout? That’s an insta L.

## 🛠️ Local Legends Only
- If you're not on the roster, don’t touch the code. Go start a fan club instead.
- Pulling the project just to poke around? Cool. Shipping changes? That’s a red flag, bestie.

## 🧠 Brainrot Protocol (Read Twice)
- Respect the README drip. If you break the vibes, we break your PR.
- No "quick fixes", no “just refactored lol”. Keep your hands in your pockets unless summoned.
- Documentation tweaks count as contributions. That means they’re also a no-go. 💅

## ☎️ Wanna Help?
1. DM the maintainers with a PowerPoint, elevator pitch, and 4k resolution vibe check.
2. Wait for approval (spoiler: it’s probably not happening).
3. If we toss you a DM back, congrats—you’re fam. Otherwise, stay hydrated and keep scrolling.

## Final Word 🧌
This repo’s got max rizz already. If you ain’t part of the core build, smash that ⭐ button and cheer from the bleachers. Appreciate the hype, but contributions? That’s a negative, ghost rider. 🛫
